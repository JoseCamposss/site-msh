# Site MSH

Website para a Manuel da Silva Henriques – Representações, Lda. (armazenista/grossista de combustíveis, metais, materiais de construção, ferragens e ferramentas).

## Estado atual

Versão inicial estática (HTML/CSS/JS puro, sem dependências) com:
- Página inicial com apresentação da empresa
- Secção de categorias de produtos (placeholder, sem catálogo real ainda)
- Secção "Quem Somos"
- Secção de contacto (dados por preencher)

Sem backend e sem pagamentos por agora — a ideia é validar o design com a empresa antes de avançar para catálogo real, encomendas e pagamentos.

## Como ver o site

Basta abrir `index.html` num browser. Não precisa de instalar nada.
